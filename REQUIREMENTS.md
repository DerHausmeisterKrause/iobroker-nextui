# Requirements

## General
- Completely customizable smart home visualization
- No mandatory device templates
- No coding required for standard functionality
- Responsive design
- Light and dark mode
- Offline/local operation

## Widgets
- Switches, buttons, dimmers, sensors
- Text, Markdown, HTML, JSON
- Charts with configurable history
- Images, cameras, tables
- Energy flow and PV widgets
- Custom containers and popups
- Unlimited nesting where technically feasible
- Reusable widget templates

## Datapoints
- Bind arbitrary ioBroker datapoints
- Separate read and write bindings
- Value transformation
- Conditional formatting
- Boolean, number, string and JSON support
- Multiple datapoints per widget
- No forced automatic interpretation

## Editor
- Drag and drop
- Responsive and free positioning
- Live preview
- Undo and redo
- Widget templates
- Copy, paste, import and export

## Backend
- Runs as ioBroker adapter
- Configurable HTTP port
- Multiple independent instances
- Server-side camera streaming
- Server-side authentication and authorization
- Secure access to internal resources

## Users
- Independent navigation per browser session
- User and group permissions
- Optional page-level authentication
- Private or shared dashboards

## Professional use
- Backup and restore
- Diagnostics
- Versioning and rollback
- Installer and customer roles
- Configuration migration
- Audit logging
